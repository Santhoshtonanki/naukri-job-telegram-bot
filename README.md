# Naukri Job Telegram Bot

Automated job notification system using GitHub Actions and Telegram.

## Job Categories

- DevOps Engineer
- AWS DevOps Engineer
- Junior DevOps Engineer
- Cloud Engineer
- DevOps Associate
- SRE
- Site Reliability Engineer
- Platform Engineer

## Location Preferences

- India - Any Location
- Remote
- International - Visa Sponsorship

## Features

- Automated job search
- Job filtering
- Duplicate job detection
- Telegram notifications
- GitHub Actions scheduling
